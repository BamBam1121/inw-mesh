SQUATCH MESH

// MeshCore firmware for the LilyGo T-Lora Pager

root@pager:~$ ./install squatch-mesh radio sx1262 ............ ok meshcore companion ...... ok messages, map, tools .... ok phone app over ble ...... ok > plug the pager in over USB-C and pick an option below.

Install

This browser can't talk to USB serial devices. Use Chrome or Edge on a computer.

Update

Already running Squatch Mesh? This replaces the app and keeps your settings, contacts and messages. It also restores the bootloader and partition table if they have gone missing.

First install

Coming from other firmware. Also writes the partition table, so the first start formats storage (a few minutes). Contacts and channels can be pulled from the SD card, see below.

There is no need to tick "erase device". If the flash is erased, everything on the pager goes with it, including your contacts and channels. Nothing brings those back except a backup.

Both options write the bootloader and the partition table, so either one can revive a pager that will not start. Update keeps your contacts, channels and settings. First install is for a pager coming from other firmware: its first start formats storage (a few minutes) and contacts come back from the SD card. If a pager still will not start, hold BOOT, tap RESET, release BOOT, and run first install again: that works even on a completely blank chip.

What it does

  • Channels, DMs and room servers, with delivery ticks, retries and how many repeaters heard your post
  • Colour emoji, @mentions, quick replies
  • Four themes (Squatch, Blocks, Hero, Aurora) with their own scenes, sounds and vibration
  • Up to 2000 contacts, sorted by recency, name or distance
  • Repeater admin: login, status, telemetry, trace, console
  • Offline map from SD tiles, downloading missing tiles over Wi-Fi
  • NFC: read and write tags, and let a phone tap the pager to get your contact or a channel invite
  • Discover nearby repeaters, packet sniffer, radio stats
  • Works with the MeshCore phone app over Bluetooth (PIN 123456)
