Squatch Mesh for the T-Deck

For the LilyGo T-Deck and T-Deck Plus. Made for the touchscreen: a home screen of your newest chats and big buttons, swipe up to unlock, tap to answer. The keyboard and trackball work everywhere too. Version 1.2.2-beta1.

Not tested on a real T-Deck yet. It is built from the T-Deck drivers other firmware uses on real units, and every screen has been run in a simulator, but this is its first time on hardware. If something is wrong it will not harm the T-Deck: you can always flash Meshtastic or MeshCore back (how). Not for the T-Lora Pager — that is the normal installer.

Before you flash

Coming from MeshCore

In the MeshCore app, export the config (it holds your private key, contacts and channels). Copy the .json to the SD card's top folder, rename it meshcore-backup.json and leave the card in. The first start brings your identity, contacts and channels across. Keep that file private.

Coming from Meshtastic

Meshtastic keys can't be carried over, so the T-Deck starts with a new identity. Write down anything you want to keep (channel names and keys, your node name) first. Flashing Meshtastic back later sets it up fresh.

Flash the T-Deck

Switch it on, plug it in, press start

Use a USB-C cable that carries data. It checks what's on the T-Deck, installs or updates, and waits for it to start. About two minutes. Chrome or Edge on a Mac, Windows or Linux computer; no drivers needed.

Your browser will ask which USB device to use — pick the one named USB JTAG/serial debug unit (on a Mac, cu.usbmodem…).

This browser can't flash over USB. Use Chrome or Edge on a desktop computer.

Going back

  

    
Both of these erase the T-Deck and install fresh, from
    Chrome, with the T-Deck in download mode if they can't connect:
    Meshtastic web flasher (pick T-Deck) ·
    MeshCore web flasher (pick LilyGo T-Deck,
    Companion).

  


  
Other ways to flash

  

    
One file with everything, written at address
    0x0: squatch-mesh-tdeck-1.2.2-beta1-full.bin.
    Use it with Espressif's web flasher
    (address 0x0, don't erase first), or esptool:

    
esptool.py --chip esp32s3 write_flash 0x0 squatch-mesh-tdeck-1.2.2-beta1-full.bin
