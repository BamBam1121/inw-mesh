Restore a repeater's identity

Puts a saved private key on a MeshCore repeater over USB, so it comes back as the same node (same name in everyone's contacts, same admin logins). Chrome or Edge on a computer.

Your key stays on your computer. The file is read in this browser and sent only to the board over USB; nothing goes to our site. Only one board may use a key at a time: turn the old one off, or give it a new key, before this one goes on the air.

1. Load the key

The repeater's config export from config.meshcore.io (a config-repeater-....json with the key in it), or paste the 128-character private key.

No key loaded.

2. Put it on the repeater

Plug the repeater in, close config.meshcore.io and any other tab using it, then pick its port. It sets the key, restarts the board and checks which node it is afterwards.
