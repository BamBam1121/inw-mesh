Squatch Mesh for the ThinkNode M9

For the Elecrow ThinkNode M9. The T-Deck's screens, driven from the keyboard: the arrow keys move, Enter picks and sends, Back or Del goes back, and Home locks the screen or wakes it. Version 1.2.6-beta1.

Not tested on a real M9 yet. It is built from the M9 support of the firmwares that run on it, checked against what was learned on real units, but this is its first time on hardware. If something is wrong it will not harm the M9: you can always flash MeshCore or Meshtastic back (how). Not for the T-Deck or the T-Lora Pager — they have their own installers.

The SD card some M9s came with

Some M9s shipped with a Windows virus on the microSD card (Elecrow's notice). It can't run on the M9, and Squatch Mesh deletes it from the card by itself every time it starts, leaving your maps and backups alone. Until then, don't open that card on a Windows computer: ask Elecrow for a replacement or format it.

Before you flash

Coming from MeshCore

Your identity (your keys), contacts, channels and radio settings should come across by themselves: the first start reads them out of MeshCore's storage before setting up its own. That hasn't been tried on a real M9 yet, so make a backup first as well: in the MeshCore app, export the config, copy the .json to the SD card's top folder, rename it meshcore-backup.json and leave the card in. Keep that file private.

Coming from Meshtastic

Meshtastic keys can't be carried over, so the M9 starts with a new identity. Write down anything you want to keep (channel names and keys, your node name) first. Flashing Meshtastic back later sets it up fresh.

Flash the M9

Switch it on, plug it in, press start

Use a USB-C cable that carries data. It checks what's on the M9, installs or updates, and waits for it to start. About two minutes. Chrome or Edge on a Mac, Windows or Linux computer.

Your browser will ask which USB device to use — pick the one that appears when you plug the M9 in. It's named after its USB chip (often USB Serial, CH340 or CP210x; on a Mac, cu.usbserial… or cu.wchusbserial…).

This browser can't flash over USB. Use Chrome or Edge on a desktop computer.

Updates

  

    
Put the M9 on Wi-Fi once (Settings ›
    Wi-Fi) and it updates itself: it looks every few hours and installs a new version while it's
    idle, keeping your contacts and settings, then says so. While the M9 build is a beta, every fix goes
    out this way. Settings › System › install updates by itself turns that off.
    Pressing start on this page updates it too, any time.

  


  
Going back

  

    
Both of these erase the M9 and install fresh, from Chrome:
    MeshCore web flasher (pick ThinkNode M9) ·
    Meshtastic web flasher (pick ThinkNode M9).
    Elecrow's own firmware and tools are on their wiki.

  


  
Other ways to flash

  

    
One file with everything, written at address
    0x0: squatch-mesh-thinknode-m9-1.2.6-beta1-full.bin.
    Use it with Espressif's web flasher
    (address 0x0, don't erase first), or esptool:

    
esptool.py --chip esp32s3 write_flash 0x0 squatch-mesh-thinknode-m9-1.2.6-beta1-full.bin
