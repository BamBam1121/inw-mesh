privacy

What we collect

Short version: nothing of our own. No accounts, no sign-up forms, no cookies, no analytics, no ads. The one exception: Cloudflare may set a short-lived security cookie if it needs to check a visitor is not a bot. Last updated 16 September 2026.

This website

squatchmesh.com is a set of static pages served from a small home server. Like almost every web server, it keeps a short access log: the address that requested a page, the page, the time and the browser's name. The log exists to spot problems, is capped at a few megabytes and overwrites itself, and is never shared or used to identify anyone.

Outside services your browser talks to

Cloudflarecarries all traffic to this site and protects it from attacks; it sees your IP address like any network provider. See Cloudflare's privacy policy.
Google Fontsthe page fonts load from Google, which receives a normal web request. See Google's privacy policy.
GitHubthe release list, the version number and the firmware files come from GitHub. See GitHub's privacy statement.
unpkgthe install page loads the open-source ESP Web Tools flasher from unpkg.

Flashing from your browser

The installer talks to your pager over USB inside your own browser. Firmware is downloaded to your computer and written to the device; nothing is read off the pager or sent anywhere. The releases page keeps the release list in your browser for ten minutes so it doesn't ask GitHub again on every visit. That is not a cookie, and it never leaves your computer. Closing the privacy notice is remembered the same way, in your browser, so it doesn't show again.

The firmware

Squatch Mesh has no telemetry and phones home to no one. It only uses the internet when you turn Wi-Fi on: checking GitHub for updates, and downloading map tiles from OpenStreetMap if you enabled that. Messages travel over LoRa radio, not the internet. Channels are readable by anyone who knows the channel name; direct messages are encrypted end to end. Your position is only shared if you turn position sharing on.
