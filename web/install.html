Quick start

Plug it in and press start

It checks the pager, works out whether it needs an update or a full install, keeps your contacts and settings safe, and fixes the usual problems on its own. About 90 seconds.

Chrome or Edge on a desktop. Your browser will ask which USB device to use — pick the pager.

This browser can't flash over USB. Use Chrome or Edge on a desktop computer.

Before a first install: keep your keys and contacts

  

    
A first install replaces the pager's storage. Squatch Mesh
    brings your identity (your keys), contacts and channels across from the SD card on its first
    start, so get them onto the card before you flash, and leave the card in.

Have a MeshCore config export?

      
If you have a MeshCore .json config export of
      this pager (it holds the private key, contacts and channels), copy it to the SD card's top folder and
      rename it meshcore-backup.json. The first start imports your keys, name, radio settings,
      contacts and channels from it. Keep that file private: anyone with it can pretend to be you.

    

    

      
Coming from Ripple, Meshtastic or the factory firmware

      
Their keys can't be carried over (Ripple keeps them
      locked away, Meshtastic uses a different kind of key), so the pager starts with a new identity.
      Write down anything you need, like private channel names and secrets, before you flash.

      Flashing…
      
    

    

    

      
      
      
    

  


  

    There is no need to tick "erase device". Erasing wipes everything on the pager,
    including its bootloader, and takes your contacts and channels with it. Both buttons write
    the bootloader and partition table, so either one can bring back a pager that will not
    start — but nothing brings back data an erase removed.
  


  
Coming from 1.0.x

  

    
Wi-Fi updates need the newer two-slot layout, so do one
    first install. Back up to SD first: on the pager, Settings → System → how to enable
    wi-fi updates does it for you. Keys, channels and settings are kept either way; contacts and
    messages come back from the SD card. After that, updates arrive over Wi-Fi and you can leave the
    cable in a drawer.

  


  
If something goes wrong

  

    

      
No port shows up

      
Use a data USB-C cable, try another port, and close anything
      else holding the serial port (Arduino IDE, a serial monitor, another browser tab).

    

    

      
It will not connect

      
On the pager: Settings → System → usb flash mode,
      then click install. On 1.1.5 or older, hold BOOT, tap
      RESET, release BOOT.

    

    

      
It will not start afterwards

      
Hold BOOT, tap RESET,
      release BOOT, then run first install again. It writes the bootloader, partition table and
      firmware, so it brings back even a completely blank chip. No other tools needed.

    

    

      
Where did my contacts go

      
Update keeps them. First install formats storage and restores
      from the SD card, so keep a card in the pager. Backups run daily to /inw/.
