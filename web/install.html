Install
install

Flash it from your browser

Chrome or Edge over USB. Nothing to download, nothing to install on your computer. Latest release: v1.1.x.

01

Plug in USB-C

Use a cable that carries data, not a charge-only one. That is the single most common reason no port appears.

02

Pick update or first install

Update keeps everything. First install is for a pager coming from other firmware.

03

Wait for it to boot

Update is quick. A first install formats storage on the first start, which takes a few minutes.

Two ways in

Update

Already running Squatch Mesh. Your contacts, channels, messages and settings stay exactly as they are. It also restores the bootloader and partition table if they have gone missing, so it can revive a pager that will not start.

Your browser cannot flash over USB. Use Chrome or Edge on a desktop. Serial access was blocked. Allow it and try again.

First install

Coming from other firmware, or recovering a pager that will not start. Writes the bootloader, partition table and app, so it stands on its own.

Your browser cannot flash over USB. Use Chrome or Edge on a desktop. Serial access was blocked. Allow it and try again.

There is no need to tick "erase device". Erasing wipes everything on the pager, including its bootloader, and takes your contacts and channels with it. Both buttons write the bootloader and partition table, so either one can bring back a pager that will not start — but nothing brings back data an erase removed.

Coming from 1.0.x

Wi-Fi updates need the newer two-slot layout, so do one first install. Back up to SD first: on the pager, Settings → System → how to enable wi-fi updates does it for you. Keys, channels and settings are kept either way; contacts and messages come back from the SD card. After that, updates arrive over Wi-Fi and you can leave the cable in a drawer.

If something goes wrong

No port shows up

Use a data USB-C cable, try another port, and close anything else holding the serial port (Arduino IDE, a serial monitor, another browser tab).

It will not connect

On the pager: Settings → System → usb flash mode, then click install. On 1.1.5 or older, hold BOOT, tap RESET, release BOOT.

It will not start afterwards

Run first install again; it writes a bootloader. If it is still dead, installing Launcher gives it a known good bootloader, then run first install.

Where did my contacts go

Update keeps them. First install formats storage and restores from the SD card, so keep a card in the pager. Backups run daily to /inw/.
