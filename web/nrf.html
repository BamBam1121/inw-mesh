Powersaving Firmware

MeshCore v1.18 repeater firmware with our traffic filter, on EasySky's PowerSaving base. The filter stops repeating far-away overhead (requests, replies and channels nobody here uses), and the radio naps between checks for packets. Less airtime, longer battery.

1. Pick your board

2. Install in your browser

Chrome or Edge on a computer. Plug the board in with a USB data cable, then:

  1. The first button asks for the board's port, then restarts the board into update mode.
  2. The second button asks for a port again: pick the new one that just appeared (on Windows it usually has a different COM number). Then it installs, in about half a minute.

Board doesn't answer? Double-tap its reset button instead, then use only the second button.

Ready.

3. Set it up

Once it's installed, give your repeater its settings with MeshCore's own setup page, over the same USB cable. Nothing to install.

Open MeshCore setup

  1. Close this page's connection first: only one page can use the board at a time.
  2. On the setup page, connect and pick the board's normal port (not the update port).
  3. Set the radio frequency your area uses, a name, and your location if you want it on the map.
  4. Change the admin password from password, then save.

Updating a repeater that was already set up? Its settings stay, so you can skip this.

Or flash the file yourself

  1. Drag and drop: double-tap the reset button so a drive appears (XIAO-SENSE or RAK...), then drag the board's .uf2 onto it. It restarts by itself when done.
  2. Bluetooth: send the repeater start ota as admin, then give the .zip to the nRF Device Firmware Update app. Stay close: a failed update needs USB to recover.

After installing

Updating a MeshCore repeater: your identity and settings stay. New board or coming from other firmware: set your radio frequency and name first, and change the admin password right away. The default is password.

ver                  check the version
tf                   filter status and counts
tf off | tf on       filter off or on
tf hops 10           change the far limit (default 8 hops)
tf allow #name       let a far channel through
get radio.rxps       radio naps (set radio.rxps off to listen all the time)

How the filter decides: RAK 1W page.

Going back

Flash the standard repeater for your board from the MeshCore flasher. Problems: support@squatchmesh.com.
