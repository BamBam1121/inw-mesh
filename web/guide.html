Buttons & power

Three buttons along the bottom edge, left to right:

leftReset. Restarts the pager. Nothing is lost.
middle tapscreen off, or on again. The radio keeps listening, so messages still arrive and light it up.
middle holdafter a couple of seconds, Power off? Press Enter (or the wheel) to turn it off; any other key cancels. Also in Settings → power off.
middle ×5five fast taps start an SOS countdown (set it up under Tools → field). Any key cancels it.
right hold 1sTurns it on after a power off. Plugging in USB does too. It only turns the pager on; it can't do anything else, because it is wired to the charger, not the processor.

Powered off really is off: it uses almost nothing, and it hears nothing either, so messages sent while it's off are missed. It can't turn off while USB is plugged in (the charger keeps it running), and it turns itself off properly when the battery is empty rather than running the cell flat. For flashing: hold middle (BOOT), tap left (reset), let go of middle.

First start

Give the node a name when it asks; that is how you appear to everyone else. Then check Settings → Radio & Mesh and pick the preset for your area if it is not already set. A fresh install formats storage first, which takes a few minutes and only ever happens once.

Updates

Settings → System → check for updates, or leave "check on start" on and it will offer them when a new release appears. It always asks first. Turning on beta updates gets you builds before they are released, which is useful if you want to help find problems and tolerable only if you do.

Battery

Settings → Battery shows charge and battery health, and holds the two power features. Optimised charging learns roughly when you unplug and holds at 80% until shortly before, which is easier on the cell; it needs a few days of routine before it does anything. Battery saver switches on at 20% and turns off GPS, Bluetooth and Wi-Fi until you are back above 80%. If health looks wrong on a new battery, use reset battery learning and let it do one full charge and one good discharge.

Notifications

Global settings live in Settings → Notifications, including quiet hours. Any single chat can override them from its own menu, or from the menu on any message in it: all messages, @mentions only, silent, or muted. Muted chats still count as unread.

Keep a card in it. A first install formats internal storage, and the card is what brings your contacts back.

Radio defaults

Ships with the Inland Northwest preset: 910.5250244 MHz, 62.5 kHz, SF7, CR 4/5. Any MeshCore radio settings work, so set whatever your local mesh uses. Everyone on a mesh has to agree on these or you will hear nothing.
